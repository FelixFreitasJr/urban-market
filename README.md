# Urban Market 🛒

Um site fictício de mercado criado como projeto prático de curso.  
O objetivo é demonstrar a estrutura básica de um site institucional com páginas de navegação, tabela de produtos e formulário de cadastro.

---

## 📂 Estrutura do Projeto

- **index.html** — Página inicial com apresentação e navegação.
- **pages/sobre.html** — Informações sobre a empresa.
- **pages/tabela.html** — Lista de produtos com imagens e preços.
- **pages/cadastro.html** — Formulário para cadastro de novos produtos.
- **css/style.css** — Arquivo de estilos para layout e cores.
- **img/** — Pasta com logomarca, ícones de redes sociais e imagens de produtos.

---

## 🎨 Design e Estilo

O projeto utiliza:
- **Fundo amarelo vibrante** com carrinho de compras como background.
- **Logomarca exclusiva** criada para o Urban Market.
- Paleta de cores:
  - Amarelo (#f2b705) para destaques.
  - Preto (#222222) para navegação e textos fortes.
  - Branco com transparência para caixas de conteúdo.
- **Tipografia:** Arial, sans-serif.
- Layout responsivo com centralização de conteúdo e espaçamento adequado.
- Efeitos visuais:
  - Hover nos links de navegação e botões.
  - Sombras e bordas arredondadas em caixas de conteúdo.
  - Ícones de redes sociais com efeito de zoom ao passar o mouse.
